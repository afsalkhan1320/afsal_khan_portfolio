# Afsal Khan - Portfolio

This is my personal portfolio website. It has my intro, skills, projects, certifications and a contact form, all on one page.

🔗 **Live Demo:** [afsal-khan-portfolio.vercel.app](https://afsal-khan-portfolio.vercel.app/)

## Sections

- **Home** - short intro with my name and role (Web Developer / Software Testing)
- **About** - a bit about me and what I do
- **Skills** - HTML, CSS, JavaScript, Bootstrap, React, Python, Excel, MySQL (these are my overall skills shown on the page - the portfolio site itself is built with HTML, CSS and Bootstrap only)
- **Projects** - my two main projects, Spicello and CineNo, with live demo and GitHub links for each
- **Certifications** - Frontend Development, Software Testing, SQL, and my internship certificate, each with a link to view the actual certificate
- **Contact** - phone, email, LinkedIn, GitHub, and a working contact form

## Tech I used

- HTML, CSS
- Bootstrap for layout, components, and the mobile navbar toggle
- Web3Forms for the contact form (works through a plain HTML form submit, no JavaScript needed)

## Why I built this

I needed one place to put my projects, skills and certificates together, instead of just sending a resume. This is what I share with recruiters along with my resume.

## Note

I built most of this myself. I used AI tools (Antigravity) for some help with layout and styling in a few sections, not the main content or structure.

## Run it locally

Just open `index.html` in your browser, no build step needed.
